Privacy Policy

personal-assistant · last updated 4 September 2026

personal-assistant is a private, single-user Telegram assistant built and operated by one individual for their own use. It is not a commercial product, has no other users, and is not offered to the public. This policy describes exactly what it touches.

Who operates it

Michael Goldenberg. Contact: golden.mihel@gmail.com.

Google data it accesses

  • calendar — read and create calendar events on request.
  • tasks — read and create tasks on request.
  • gmail.readonly — read message metadata and content to answer questions about email. It cannot send, modify, or delete mail.

Access is granted by the account owner through Google's own consent screen and can be revoked at any time at myaccount.google.com/permissions. Revoking access immediately and permanently stops all data access.

Where the data goes

Two places, and nowhere else:

  • The operator's own computer. All language-model inference runs locally via Ollama, and all speech-to-text runs locally via Whisper. No message content, calendar entry, task, or email is sent to any third-party AI service.
  • The operator's own AWS account (region eu-central-1), which handles message delivery only. It stores Telegram message text briefly in transit, voice recordings, and recent conversation history.

How long it is kept

  • Voice recordings — deleted automatically after 7 days by an S3 lifecycle rule.
  • Conversation history — deleted automatically after 7 days of inactivity by a DynamoDB time-to-live attribute.
  • Queued messages — discarded after 1 hour if not processed.
  • Operational logs — deleted after 7 days. They record events and message lengths, not message content.

Google data itself is never copied into long-term storage. It is fetched when a question needs it, used to answer, and discarded.

What is never done

  • Data is never sold, rented, or shared with any third party.
  • Data is never used to train any machine-learning model.
  • There is no advertising, tracking, profiling, or analytics of any kind.
  • No other person has access. The assistant refuses every Telegram user except the operator.

Security

  • Credentials are held in AWS Systems Manager Parameter Store as encrypted SecureStrings, never in source code or configuration files.
  • The public webhook authenticates every request against a shared secret and rejects any message from an unrecognised Telegram user.
  • All storage is encrypted at rest and blocked from public access; all transport is HTTPS, with plaintext requests explicitly denied.
  • The source code is public at github.com/mishgoldenberg/telegram-agent-aws and can be inspected to confirm all of the above.

Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes
