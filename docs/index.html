personal-assistant

A private, single-user Telegram assistant. Local language model, AWS ingest path.

This is the home page for a personal project: a Telegram bot that manages one person's calendar, tasks, and email. It has exactly one user — its author — and is not offered to anyone else.

How it works

Telegram  ->  API Gateway  ->  Lambda  ->  SQS
                                            |
                          (outbound long poll, no inbound access)
                                            v
                              local machine: Whisper + Ollama
                                            |
                                            v
                                     Telegram reply

Message delivery, queueing, and short-term state run in the author's own AWS account. Everything that reads the actual content — speech-to-text and the language model — runs on the author's own hardware and never leaves it. No third-party AI service sees any message, calendar entry, task, or email.

Why the split

The language model runs on a GPU that cannot leave the house, so the parts that can move to the cloud did: the public HTTPS endpoint, the work queue, conversation state, and the alerting. The home network accepts no inbound connections; the local worker reaches out to the queue and never listens.

Data and privacy

Voice recordings are deleted after 7 days, conversation history after 7 days of inactivity, and logs after 7 days. Nothing is sold, shared, or used to train anything. The full detail is in the privacy policy.

Source

The infrastructure is entirely Terraform and is public at github.com/mishgoldenberg/telegram-agent-aws, so every claim on this page can be checked against the code.
